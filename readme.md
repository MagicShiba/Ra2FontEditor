## RA2字体编辑器
Red Alert 2 font editor. 
适用于红色警戒2的字体编辑器，现在已添加中英语言切换支持！

![alt text](other/base1.png)

## 主要功能  
将系统字体或加载的字体转为ra2格式字体,使用当前加载的字符范围。  
缺失的字符直接批量选中即可添加。  
手动编辑任意符号，并有辅助线便于对齐定位。  
可通过搜索快速定位字符位置。  
批量调整符号宽度和居中，可用于制作等宽字体。  
通过使用不同字体的字符在游戏中获得最佳显示。  
分离共用数据的字符占位字符。  
预览字体显示效果。  
简繁转换简化输入。  

## 使用
双击打开 `FontEditor.html` 即可。  
点击左上角**加载区**或从**外部拖放游戏字体**，在`fnt`文件夹内提供了几个字体文件，或者从游戏目录中寻找 `game.fnt` 。  
加载后点击具体的字符，然后在中间编辑区域查看或修改字符。
在右边栏选择**系统字体**或**拖放外部字体**。  
| ![alt text](other/qxzt.png)              |
| ------------------------------------------ |
| `允许以获取系统字体列表，否则使用内置列表` |

你可以一键转换全部字符为指定字体。  
如果你想修改部分字符为指定字体，需要在左侧选中字符。
 - 你可以勾选复选框或shift/ctrl+鼠标框选进行批量选择或取消
 - 你可以批量设置宽度或居中，这可用于制作等宽字体
 - 你可以在左侧搜索，可以通过简繁转换输入简体搜索对应繁体

如果你想修改字符宽度需要在右侧符号参数中修改。  
相关文档中说每个字符限制256个像素，即16x16或15x17,因此不建议修改字体整体的宽高。  

但实际上看起来可以适量超过，比如17x17，20x20，字符过大是会造成显示不全，数字字符过大时会造成资金闪烁或显示不完整，如果你希望使用更大的字体，则注意需要调整下数字的位置。
 - 受字体和不同实现等原因，你可以选比15大一些的字体，但宽度仍然在15内，默认的16是比较通用的大小。  
 - 这是20的黑体：  
![alt text](other/nn3.png)

由于一次性加载或处理数万字符，因此有时卡一下是正常的。  
在大量生成字符时需要时间较久，可以通过进度条查看进度或取消。
